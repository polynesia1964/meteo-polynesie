🌍 Stations météo de Polynésie française
Données de localisation et d’identification des postes météorologiques
(English version below)

Ce dépôt contient un fichier CSV regroupant les principales informations sur les stations météo de la Polynésie française.
Il est destiné aux développeurs, cartographes, chercheurs ou toute personne ayant besoin d’accéder rapidement aux coordonnées géographiques ou aux métadonnées des postes météo.

📄Contenu du fichier CSV
Le fichier postes_complets-2026.csv inclut pour chaque station :

Nom de la station
Identifiant interne
Commune
Latitude
Longitude
Altitude
Code OACI (si disponible)
Dates d’ouverture et de fermeture
Si la date de fermeture est null, la station est considérée comme active

🎯 Objectif du dépôt
Ce fichier est conçu pour être intégré facilement dans des scripts JavaScript, notamment pour :
Générer des cartes interactives
Accélérer le développement d’applications cartographiques
Tester des bibliothèques comme Leaflet
Manipuler rapidement les coordonnées des stations météo

📬Utilisation
Les données sont fournies telles quelles, à titre informatif.
Elles peuvent être utilisées pour des projets personnels, éducatifs ou expérimentaux.

ENGLISH VERSION

🌍 Weather Stations of French Polynesia
Location and identification data for meteorological stations

This repository contains a CSV file gathering key information about weather stations across French Polynesia.
It is intended for developers, cartographers, researchers, or anyone needing quick access to geographic coordinates or metadata for local weather stations.

📄 CSV File Contents
The postes_complets-2026.csv file includes, for each station:

Station name
Internal identifier
Municipality
Latitude
Longitude
Elevation
ICAO code (when available)
Opening and closing dates
If the closing date is null, the station is considered active

🎯 Purpose of the Repository
This dataset is designed to be easily integrated into JavaScript scripts, especially for:

Building interactive maps

Speeding up cartographic application development

Testing libraries such as Leaflet

Quickly manipulating station coordinates

📬 Usage
The data is provided as‑is, for informational purposes.
It may be used for personal, educational, or experimental projects.
